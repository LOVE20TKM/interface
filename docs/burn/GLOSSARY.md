# 销毁与锁定前端术语

本文件定义“销毁与锁定”页面使用的展示与交互语言。Burn 协议概念以 `burn/CONTEXT.md` 为准，本文件只补充前端需要区分的名称。

## Language

**Burn 活动**：
由一个 Burn 合约部署定义的完整活动，包含其配置的全部参与社区、销毁周期、份额计算及可选空投，而不是当前选中代币的单社区活动。
_Avoid_: 当前代币销毁、单社区销毁

**全局参与概况**：
一个 Burn 活动的轮次状态、参与地址数和份额状态；不同社区及不同资产类别的数量分别展示，不汇总为单一销毁数量。
_Avoid_: 总销毁数量、总销毁量

**轮次参与状态**：
指定参与社区和销毁轮次内，四类资产的社区统计、个人统计及销毁得分；历史轮次与开放轮次含义相同，但不再允许补做任何锁定或销毁。
_Avoid_: 逐笔销毁历史、跨轮累计

**预计份额**：
Burn 活动进行中，地址按全周期累计得分计算的跨社区实时份额；后续参与行为仍会改变该结果。
_Avoid_: 单轮份额、固定空投比例、最终份额

**最终份额**：
Burn 活动结束后，地址按全部参与社区和全部销毁轮次累计得分确定的分配比例。
_Avoid_: 单轮份额、空投代币数量、销毁得分

**本轮得分加成**：
指定参与社区和销毁轮次中，相比最后一轮基础得分额外获得的得分比例；同一社区该轮的四类资产使用相同加成。
_Avoid_: 销毁奖励、额度倍数、空投加成

**凭证永久锁定**：
通过 Burn 将 SL 或 ST 凭证不可逆地转入对应社区代币合约；该操作不是代币销毁。
_Avoid_: SL 销毁、ST 销毁

**整笔凭证锁定**：
销毁参与者将当前持有的某种 SL 或 ST 凭证余额全部永久锁定，以免部分转出使对应质押记录的有效治理票数归零。
_Avoid_: 部分锁定

**激励代币真实销毁**：
Burn 收取参与者持有的社区代币并调用该代币的销毁能力，从而降低其总供应量。
_Avoid_: 激励锁定、凭证销毁

**实际铸造激励**：
地址在指定社区、轮次和治理或具体行动来源中已经完成领取并实际铸造的激励数量；尚未领取的可领取激励不属于实际铸造激励。
_Avoid_: 理论激励、可领取激励、行动激励总和

**预计可领取激励**：
领取交易前查询到的当轮治理或具体行动激励，只用于提示领取机会；它尚未生成激励代币销毁额度。
_Avoid_: 实际铸造激励、可用销毁额度

**激励代币销毁额度**：
指定地址、社区、轮次及治理或具体行动来源的实际铸造激励乘以 Burn 活动的额度倍数；每个行动独立生成并核销额度，未用额度不能跨行动或跨轮次转移。
_Avoid_: 钱包余额、可领取激励、跨行动总额度

**行动激励销毁总量**：
地址在同一社区和销毁轮次中跨多个行动额度使用的行动类别销毁数量；每个行动的额度仍独立核销。
_Avoid_: 跨社区销毁总量、跨轮额度、单个行动额度

**同链空投领取**：
配置空投代币的 Burn 活动结束后，销毁参与者按跨社区最终份额从动态剩余池领取一次；领取状态不属于某个社区或销毁轮次。
_Avoid_: 单社区空投、单轮空投、固定领取数量
